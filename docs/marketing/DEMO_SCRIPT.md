# Demo Script (narration)

A word-for-word script for a live or recorded ~5-minute walkthrough. All data is
synthetic; keep the language assistive and human-reviewed.

**Open (Home).** "Internal-channel inspection produces a lot of images and very
little governed evidence. LumenAI turns each inspection into a structured,
reviewable record — with a qualified person owning every decision."

**Executive view (/executive).** "Let me show you this as a [role]. Same platform,
but the metrics that matter to you lead — here, review-required rate and evidence
completeness. Everything you see is synthetic demonstration data."

**Workflow (/workflow).** "Ten labeled steps. Identify the instrument, capture the
lumen image, attach metadata. Analysis is assistive — it suggests finding
categories; it never decides. We compare against an approved baseline, produce a
*provisional* result, and route anything uncertain to a qualified reviewer."

**Governance (/security).** "Every decision is written to a hash-chained audit
trail — image, metadata, rationale, timestamp. Each stage adds to the record; it
never overwrites. That's what makes it audit-ready."

**Close (/contact).** "LumenAI supports your team — it doesn't replace technicians,
reviewers, or manufacturer IFUs. If that's useful, let's set up a pilot."

*Pauses for questions marked with … Keep to 5 minutes.*
