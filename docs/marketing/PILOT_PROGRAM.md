# Pilot Program (commercial)

Mirrors the `/pilot` page for sales/procurement use. A pilot is a bounded
**validation**, not a production rollout, and never connects the public demo to
production data.

- **Objectives:** confirm workflow fit, evidence completeness, and review routing vs local policy.
- **Timeline:** a defined evaluation window (typically a few weeks), scoped to instrument types + roles.
- **Success criteria (qualitative first):** fast/consistent documentation; reviewers act on routed findings; quality assembles audit-ready records.
- **LumenAI provides:** configuration, enablement, governed workflow + evidence + reporting, a written readout.
- **Customer provides:** named SPD lead + reviewer(s) + quality sponsor, bounded instrument set, time, synthetic/de-identified data unless a data agreement exists.
- **Deliverables & exit:** written readout + go/no-go.
- **Out of scope:** clinical-outcome, infection-reduction, or diagnostic-performance claims.
