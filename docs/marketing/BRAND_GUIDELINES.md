# Brand Guidelines

Source of truth for the LumenAI visual system (marketing site).

## Color (from frontend/src/index.css tokens)
- Primary indigo `#4f46e5` (hover `#4338ca`, active `#3730a3`, subtle `#eef2ff`)
- Neutrals: slate-navy `#0f172a` → `#1e293b`, slate greys for text/borders
- Semantic: success / warning / info tokens (see index.css)

## Typography
- System UI sans stack; bold headings, relaxed body; capped line length (`max-w-*`).

## Logo usage
- Wordmark "LumenAI"; keep clear space; do not recolor the primary mark arbitrarily.

## Illustration / iconography
- lucide icons, thin/precise. **No** robots, glowing brains, neon, or sci-fi imagery.
- Diagrams are clean, labeled, clinical. Motion is restrained; respect reduced-motion.

## Voice
- Precise, trustworthy, evidence-focused. Assistive / decision-support / provisional.
- Never: causation, outcome, accuracy %, savings, or certification claims.
