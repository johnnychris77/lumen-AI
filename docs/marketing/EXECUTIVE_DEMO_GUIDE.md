# Executive Demo Guide

How to give a confident 5-minute LumenAI demonstration to a hospital executive,
SPD leader, or investor. Public site: `/` → key stops below.

## The 5-minute path
1. **Home** — one sentence on the problem + the "governed evidence" promise (30s).
2. **/executive** — pick the visitor's role; the KPIs and message reframe to them (60s).
3. **/workflow** — walk the ten steps; run the interactive demo with synthetic data (120s).
4. **/security** or **/architecture** — human oversight + evidence governance (45s).
5. **/contact** — request a demonstration / discuss a pilot (15s).

## What every executive should take away
- The **problem** (loose images/spreadsheets → no traceability).
- **How it works** (capture → assistive analysis → baseline → human review → governed evidence → report).
- **How evidence is governed** (hash-chained audit trail; each stage adds, never overwrites).
- **AI assists, humans decide** (nothing is auto-passed; uncertain/high-risk routes to review).
- **Why adopt** (audit-ready evidence, comparability, defensible records).

## Guardrails (say these, never overclaim)
- "Assistive," "decision support," "provisional," "demonstration data."
- Never claim outcomes, infection reduction, accuracy %, savings, or certification.
- Every number on screen is **synthetic**.
