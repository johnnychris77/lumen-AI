# Implementation Guide (marketing-facing overview)

A plain-language overview of how a LumenAI adoption is sequenced. This is a
commercial overview — technical/production deployment is governed by the product's
own engineering runbooks, not this document.

## Phases
1. **Evaluate** — executive demo + workflow review (this website).
2. **Pilot** — bounded validation with named roles (see `PILOT_GUIDE.md`).
3. **Configure** — baselines, roles/permissions, review routing, report templates.
4. **Train** — technicians and reviewers on capture, review, and evidence.
5. **Routine use** — inspections flow through the governed workflow.
6. **Report & improve** — trends and audit evidence inform continuous improvement.

## Roles
- **SPD technicians** — capture + document; act on assistive suggestions.
- **Reviewers** — decide routed findings; own final dispositions.
- **Quality / IP** — use governed evidence for review and audit readiness.
- **Biomed** — instrument lifecycle / digital-twin context.

## Guardrails
- Human review and manufacturer IFUs remain authoritative.
- No production data flows through the public demonstration site.
